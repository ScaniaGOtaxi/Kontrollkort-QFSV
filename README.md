# QFSV vehicle illustrations

Generated transparent PNG model illustrations for Kontrollkort QFSV. These are not photographs of the exact fleet vehicles. Scania uses the user-supplied cab reference.

Design research: JCB 427 official product page; Volvo L60H/L70H product references; Linde X35-X50 product references; Kalmar DCG200-12 model references; New Holland T6.175 Auto Command; Valtra N155e; Hako Citymaster 1600; Volkswagen Crafter box body and ID. Buzz Cargo. Original fleet thumbnails and the uploaded control-card PDF were used as visual references.

Transporter is unchanged and is managed in the application.
